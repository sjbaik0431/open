연결 우선순위 가이드

OAuth 방식 연동은 본인 로그인·동의가 필요해 Claude가 대신 인증을 완료할 수 없습니다. claude.ai → 설정(Settings) → 연동(Connectors)에서 아래 순서대로 "연결" 또는 "재연결" 버튼을 눌러주세요.

  1. 1순위 — 재무/결제 즉시 연결: Intuit QuickBooks(회계 자동화), PayPal(인증 재시도), Canva(디자인 제작)
  2. 2순위 — 협업 확장: Microsoft 365(SharePoint/OneDrive/Outlook), 아사나(프로젝트 관리), 아틀라시안, 스퀘어(결제)
  3. 3순위 — 기존 재연결 항목 복구: zapier(자동화, 계정 1개로 통합 권장), 파일 크롤링, 마크다운, 클라우드, bllender(3D)
  4. 4순위 — 정리/검토 필요: "오류"(이름 불명확, 삭제 권장), 중복 등록된 figma·notion·zapier·페이팔(하나로 통합), windows제어·브라우저(내장 브라우저/디바이스 브릿지와 기능 중복 가능성 검토)

※ 이름만 등록되고 설명이 없는 항목(오류·클라우드·마크다운·파일 크롤링·브라우저·아사나 등 한글 표기 커넥터)은 관리자 설정에서 실제 연결 대상을 먼저 확인한 뒤 재연결하는 것을 권장합니다.
